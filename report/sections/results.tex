\section{Результати роботи програми}

Для повної верифікації розроблених алгоритмів, контролю стану об'єктів та перевірки 
коректності роботи з примітивними та об'єктними типами даних, а також демонстрації механізмів 
успадкування та поліморфізму було здійснено запуск програми в єдиному циклі збирання 
середовища VS Code. На рисунку~\ref{fig:terminal_lab3} представлено фінальний вивід 
результатів у консоль Windows PowerShell.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{screenshots/terminal_output.png}
    \caption{Вигляд терміналу після успішного виконання всіх завдань Лабораторної роботи №3}
    \label{fig:terminal_lab3}
\end{figure}

На основі отриманих даних терміналу (рис.~\ref{fig:terminal_lab3}) проведено детальний 
покроковий аналіз результатів тестування:
\begin{enumerate}
    \item \textbf{Результати перевірки теоретичних прикладів:} 
    \begin{itemize}
        \item 
        При діленні цілих чисел \texttt{10 / 3} тип \texttt{int} повністю відкинув 
        дробову частину, вивівши результат \texttt{3}. Використання типу \texttt{double} 
        у виразі \texttt{10.0 / 3} дозволило отримати точний дробовий результат \texttt{3.3333333333333335}.
        \item 
        Операція додавання \texttt{0.1 + 0.2} наочно продемонструвала системну 
        похибку двійкового представлення дробових чисел у пам'яті комп'ютера, вивівши 
        результат \texttt{0.30000000000000004}.
        \item 
        Інспекція методів об'єктного типу \texttt{String} підтвердила правильність обробки 
        рядків: метод \texttt{.length()} зафіксував довжину \texttt{16} символів, а 
        метод \texttt{.charAt(0)} безпомилково витягнув перший символ \texttt{'J'}.
        \item 
        Порівняння двох різних об'єктів рядків через оператор \texttt{==} повернуло 
        значення \texttt{false} (оскільки порівнювалися адреси посилань у пам'яті), 
        тоді як логічний метод \texttt{.equals()} повернув істинне значення \texttt{true}, 
        підтвердивши повний збіг вмісту об'єктів.
    \end{itemize}

    \item \textbf{Результати виконання індивідуального завдання:}
    Сервісний компонент \texttt{MovieCatalog} успішно проітерував масив об'єктних посилань 
    базового типу \texttt{Media[]}, задіявши механізм динамічного об'єктного поліморфізму. 
    У консоль було виведено повний відформатований список із 5 кінофільмів із зазначенням 
    їхніх специфічних інкапсульованих характеристик (жанр, рік, хронометраж, рейтинг).
    
    \item \textbf{Пошук лідера рейтингу:}
    Розроблений лінійний алгоритм пошуку максимуму, що використовує безпечне приведення 
    типів за допомогою оператора \texttt{instanceof}, безпомилково визначив фільм із найвищим 
    рейтингом. Ним стала кінострічка \textbf{«Темний лицар»} із максимальною оцінкою 
    у \textbf{\texttt{9.0}} балів.
\end{enumerate}
